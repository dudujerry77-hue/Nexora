Nexora external-site integration test (this page simulates the storefront at 127.0.0.1:5500)

Serve this folder on port 5500 (e.g. VS Code "Live Server", or npx serve -l 5500 dev-tools/external-site-simulator) and open it as http://127.0.0.1:5500 or http://localhost:5500 — those are the two origins Nexora's dev-only CORS allowlist accepts (see src/lib/cors.ts).

Copy config.example.js to config.local.js in this same folder and fill in a real storeId + apiKey from Nexora's "Generate credentials" flow. config.local.js is gitignored — it never gets committed.
